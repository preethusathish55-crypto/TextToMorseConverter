# Text to Morse Code Converter

A Flask-based web application that converts plain text to Morse code and Morse code back to text. The application includes user authentication and conversion history.

## 🚀 Features

- Convert Text to Morse Code
- Convert Morse Code to Text
- User Signup & Login
- Password hashing using Flask-Bcrypt
- Conversion History
- Responsive Web Interface

## 🛠 Technologies Used

- Python
- Flask
- HTML5
- CSS3
- SQLite
- Git & GitHub
- Render
