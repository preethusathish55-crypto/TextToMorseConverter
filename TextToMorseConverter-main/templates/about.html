About This Project

MorseSecure is a modern Morse Code Encryption and Decryption System developed using Python Flask, SQLite, HTML and Tailwind CSS.

This application allows users to:

  • ✔ Convert normal text into Morse code
  • ✔ Decrypt Morse code back into readable text
  • ✔ Store conversion history using SQLite database
  • ✔ Play Morse code audio
  • ✔ Use a modern and responsive user interface
